# Changelog

All notable changes will be documented here.

## [Unreleased] — 2026-10-20

### Added
- Grapharium identity and general-purpose read-only Graphify JSON converter.
- Relation/provenance-preserving data schema, explicit containment forest, ambiguity and cycle rejection.
- Reproducible orbital layout, file systems, stars, planets, moons, event/document symbol styles.
- Instanced Three.js celestial geometry and dual-layer luminous dependency edges.
- Transparent system/nested firmaments, manual orbit, pan, zoom, keyboard navigation and object selection.
- Responsive search and metadata inspector; controls for system spacing, orbital spread, aura and detail.
- Synthetic example, automated converter/hierarchy tests, project documentation and GitHub CI.
- Privacy-first generated-output exclusions and bundled Three.js license.

### Known limitations
- Event identification depends on available Graphify role metadata.
- No true physically accurate orbits, shader bloom postprocessing or live data updates.
- Browser performance varies with GPU, graph and quality preset.
- Graphify relationship metadata may not resolve parenthood for every symbol.
